NL Console-Script Generator

Upload an NL CSV (columns: sku, title, title_specs, handle, body_html). Generates a console-script that resolves GIDs by SKU and pushes default-locale fields via productUpdate. After running, the script downloads sku-gid.csv for use in Tool B (T&A formatter).

  1. Generate the script below and copy it.
  2. Open the Shopify storefront domain in a tab — manibhadra-phoeniximport.myshopify.com/products.json works. Not the admin domain (admin overrides fetch).
  3. Open DevTools console, paste, hit Enter.
  4. Paste the admin API token when prompted.
  5. Wait for "Done" — script will trigger the sku-gid.csv download.
