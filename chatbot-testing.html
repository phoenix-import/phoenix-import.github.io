Chatbot Testing

This page hosts a live sandbox of the Watermelon.ai chat widget so we can test conversations, responses, and behaviour in isolation before rolling changes out to the storefronts.

How to use

  1. The widget loads automatically — look for the chat launcher in the bottom-right corner of this page.
  2. Open it and run through the flows you want to check (greetings, product questions, hand-off, etc.).
  3. If the launcher doesn't appear, refresh the page or check your network connection — the widget is loaded from an external script.
Testing here has no impact on live storefront chats. This is an isolated environment for the Watermelon.ai widget only.
