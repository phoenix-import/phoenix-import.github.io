Full-Pipeline Console-Script Generator

Upload one combined CSV with columns: sku, locale, title, title_specs, handle, body_html. One row per (product × locale). NL is required; EN/DE/FR/IT/ES are optional. Generates one console-script that resolves GIDs, pushes NL via productUpdate, and pushes the rest via translationsRegister.

  1. Generate the script and copy it.
  2. Open https://manibhadra-phoeniximport.myshopify.com/products.json directly in the address bar (deep paths don't redirect to the public domain).
  3. Open DevTools console, paste, hit Enter.
  4. Paste the admin API token when prompted.
  5. Wait for "Done". Script will trigger the sku-gid.csv download for record-keeping.
