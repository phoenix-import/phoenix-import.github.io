T&A CSV Formatter

Combine the SKU→GID mapping (from consolegen) with the NL CSV plus locale CSVs to produce Translate & Adapt-ready imports for EN/DE/FR/IT/ES. Each output CSV is 5 rows per product (title, body_html, handle, meta_title, meta_description).

  1. Run NL push first via consolegen — that fills default-locale fields and produces sku-gid.csv.
  2. Upload all the files below. NL is required; locales are optional — only those uploaded get T&A CSVs.
  3. Click Generate. Download each locale's CSV, then upload via Languages → Import (tick "Overwrite existing translations").
